# minecraft-neural-network
This features an analog neural network implemented in Minecraft using Redstone. It includes backpropagation (a machine-learning technique that trains neural networks by adjusting their weights based on error rates) and gradient descent (an optimization algorithm for finding a local minimum of a differentiable function).

This repository contains world files for Minecraft version 1.16.5, sorted in the order in which the network was built. The latest editions only feature minor tweaks compared to previous versions.

# How to install
1. Close Minecraft if it is already running.
2. Open your Minecraft running directory.
    By default, this is located in Roaming which can be accessed by typing "%appdata%" in your file browser. ("C:\Users\{USER}\AppData\Roaming\.minecraft")
    This can also be done by going into the options menu in Minecraft, clicking on resource packs, clicking open resource pack folder, and moving back a directory.
3. Next locate and open your "saves" folder within your Minecraft directory.
4. Download the neural network version you want from the repository and unzip it.
5. Move the unzipped file into your "saves" folder.
6. Reboot Minecraft if you left it running, the world will now appear in your single-player worlds.
